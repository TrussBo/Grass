          HOW ONLINE WORKS

          1. Same link. Everyone opens this game link on their own phone.
          2. One person hosts. CREATE GAME, then share the 4-letter code.
          3. Everyone else joins. ONLINE on the menu (or BE A LEGEND › JOIN A FRIEND'S GAME), type the code, JOIN.
          4. Pick sides. Up to 6 people in pickup, 3 in story (all HOME). The AI fills open spots. The host starts.
          5. Host: keep it open. The host's phone runs the match. If it drops out, everyone waits 20 s for it.
          6. Your own legend. Your stats, tricks and points. It saves on this device.

          Can't connect? Check the link and the code. Some Wi-Fi (school, work) blocks it: try mobile data, or everyone on the same Wi-Fi. Still stuck: reopen the game and rejoin.
